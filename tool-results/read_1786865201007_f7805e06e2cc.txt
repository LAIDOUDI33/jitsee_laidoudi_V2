     1→# ALVISION - Enterprise AI Video Conferencing Platform
     2→## Project Status: Phase 6 Complete (Live Transcription Panel + Meeting Export API)
     3→
     4→---
     5→### Current Project Status
     6→ALVISION is a comprehensive enterprise AI video conferencing and collaboration platform adapted from the JitSee Meet repository (LAIDOUDI33/jitsee_laidoudi_V2). Built on Next.js 16 with TypeScript, Tailwind CSS 4, shadcn/ui, Prisma ORM, z-ai-web-dev-sdk, and Framer Motion.
     7→
     8→### Architecture
     9→- **Framework**: Next.js 16 App Router (single `/` route with Zustand-based client-side routing for 29 views)
    10→- **Rendering**: Dynamic imports via `next/dynamic` with `ssr: false` to prevent OOM in constrained environments
    11→- **Database**: SQLite + Prisma ORM (18 normalized models)
    12→- **AI**: z-ai-web-dev-sdk for real LLM-powered meeting summaries and chat
    13→- **Auth**: Password hashing with Node.js crypto (SHA-256 + salt), session-based auth
    14→- **Real-time**: WebSocket mini-service on port 3010 (Bun.serve) for live chat with channels, typing, presence
    15→- **UI**: 85 components, shadcn/ui + Framer Motion + Recharts + Lucide icons
    16→- **State**: Zustand for global app state, client-side navigation, notifications, search
    17→- **Theme**: Light/dark mode with next-themes, ALVISION brand theme
    18→- **Codebase**: 24,770 lines of TypeScript/TSX across 109 source files
    19→
    20→### Database Schema (18 Models)
    21→1. **User** - RBAC roles (superadmin, orgadmin, teamadmin, host, participant, guest)
    22→2. **Organization** - Multi-tenancy with plans (free, pro, enterprise)
    23→3. **Team** - Organization-scoped teams
    24→4. **TeamMember** - User-team membership with roles
    25→5. **Channel** - Team channels (text, video, announcement)
    26→6. **Message** - Chat messages with threading support
    27→7. **Meeting** - Full meeting lifecycle (instant, scheduled, recurring, personal)
    28→8. **MeetingParticipant** - Meeting attendance tracking
    29→9. **Recording** - Meeting recordings with metadata
    30→10. **Transcript** - Speaker-identified transcripts with timestamps
    31→11. **MeetingSummary** - AI-generated summaries with topics, decisions, risks
    32→12. **ActionItem** - AI-extracted action items with owners and deadlines
    33→13. **Poll** - In-meeting polls with results
    34→14. **Event** - Webinars, town halls, live streams
    35→15. **EventRegistration** - Event registration management
    36→16. **File** - Enterprise file management
    37→17. **AuditLog** - Tamper-resistant audit trail
    38→18. **ApiKey** - API key management

    40→### API Endpoints (15 routes)
    41→- `POST /api/v1/auth/register` - User registration with org creation, password hashing
    42→- `POST /api/v1/auth/login` - Login with credential verification, audit logging
    43→- `GET /api/v1/meetings` - List meetings (limit 20, ordered by date)
    44→- `POST /api/v1/meetings` - Create meeting with auto-generated room ID
    45→- `POST /api/v1/meetings/schedule` - Create scheduled/recurring meeting with validation
    46→- `GET /api/v1/meetings/[id]` - Get meeting with participants
    47→- `POST /api/v1/ai/summarize` - AI meeting summary (real LLM via z-ai-web-dev-sdk)
    48→- `POST /api/v1/ai/chat` - AI chat assistant (real LLM via z-ai-web-dev-sdk)
    49→- `GET /api/v1/stats` - Platform statistics
    50→- `GET /api/v1/users` - User management
    51→- `GET /api/v1/whiteboard` - Get whiteboard data by sessionId
    52→- `POST /api/v1/whiteboard` - Save whiteboard drawing data
    53→- `GET /api/v1/chat` - Chat messages (HTTP fallback for WebSocket)
    54→- `POST /api/v1/chat` - Send chat message (HTTP fallback)
    55→- `POST /api/contact` - Contact form submission
    56→- `POST /api/newsletter` - Newsletter subscription
