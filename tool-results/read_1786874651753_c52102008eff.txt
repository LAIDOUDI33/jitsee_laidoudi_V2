     1→# ALVISION - Enterprise AI Video Conferencing Platform
     2→## Project Status: Phase 7 Complete (Bug Fixes + 2 New Features + Full Styling Sprint)

     5→### Current Project Status
     6→ALVISION is a comprehensive enterprise AI video conferencing and collaboration platform adapted from the JitSee Meet repository (LAIDOUDI33/jitsee_laidoudi_V2). Built on Next.js 16 with TypeScript, Tailwind CSS 4, shadcn/ui, Prisma ORM, z-ai-web-dev-sdk, and Framer Motion.
     7→
     8→### Architecture
     9→- **Framework**: Next.js 16 App Router (single `/` route with Zustand-based client-side routing for 33 views)
    10→- **Rendering**: Dynamic imports via `next/dynamic` with `ssr: false` to prevent OOM in constrained environments
    11→- **Database**: SQLite + Prisma ORM (18 normalized models)
    12→- **AI**: z-ai-web-dev-sdk for real LLM-powered meeting summaries and chat
    13→- **Auth**: Password hashing with Node.js crypto (SHA-256 + salt), session-based auth
    14→- **Real-time**: WebSocket mini-service on port 3010 (Bun.serve) for live chat with channels, typing, presence
    15→- **State**: Zustand for global app state + TanStack Query for server state; client-side navigation, notifications, search
    16→- **Theme**: Light/dark mode with next-themes, ALVISION brand theme
    17→- **Codebase**: 29,878 lines of TypeScript/TSX across 119 source files
    18→

    39→### API Endpoints (15 routes)
    40→- `POST /api/v1/auth/register` - User registration with org creation, password hashing
    41→- `POST /api/v1/auth/login` - Login with credential verification, audit logging
    42→- `GET /api/v1/meetings` - List meetings (limit 20, ordered by date)
    43→- `POST /api/v1/meetings` - Create meeting with auto-generated room ID
    44→- `POST /api/v1/meetings/schedule` - Create scheduled/recurring meeting with validation
    45→- `GET /api/v1/meetings/[id]` - Get meeting with participants
    46→- `POST /api/v1/ai/summarize` - AI meeting summary (real LLM via z-ai-web-dev-sdk)
    47→- `POST /api/v1/ai/chat` - AI chat assistant (real LLM via z-ai-web-dev-sdk)
    48→- `GET /api/v1/stats` - Platform statistics
    49→- `GET /api/v1/users` - User management
    50→- `GET /api/v1/whiteboard` - Get whiteboard data by sessionId
    51→- `POST /api/v1/whiteboard` - Save whiteboard drawing data
    52→- `GET /api/v1/chat` - Chat messages (HTTP fallback for WebSocket)
    53→- `POST /api/v1/chat` - Send chat message (HTTP fallback)
    54→- `POST /api/contact` - Contact form submission
    55→- `POST /api/newsletter` - Newsletter subscription
